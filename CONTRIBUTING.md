# Contributing

Use macOS 14 or newer and Swift 6. The app is SwiftUI and AppKit; keep it native and compact.

```sh
swift test
./scripts/build-app.sh
```

Changes to provider data must preserve the distinction between zero and unavailable. Do not infer subscription quota from API spending, invent reset dates, launch a model turn to measure usage, or log credentials and transcript content.

T3 Code files are read-only inputs. Never point test writers at a real `~/.t3/userdata` directory. Tests should use temporary directories and synthetic records. Authentication changes should keep credentials in their original CLI/T3 store rather than introducing another credential copy.

The pinned upstream source and hashes are in `tools/t3-source/SOURCE.json`. `entry.ts` contains the native adapter boundary. After changing extraction or wrappers, regenerate the bundle with `pnpm --dir tools run extract`, run tests, and retain upstream license notices.

Public screenshots are generated by `DocumentationScreenshots` using synthetic fixtures in the test target. Never upload screenshots or logs from a real account. Regenerate them after visual changes:

```sh
QUOTA_SCREENSHOT_DIRECTORY="$PWD/docs/screenshots" swift test --filter DocumentationScreenshots
```

For a PR, describe the user-visible change, how you checked it, and provider/platform limitations. Keep unrelated cleanup separate.
