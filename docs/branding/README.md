# Ration Token mark

Selected logo direction **D — Token**. A geometric white token with open counters and a diagonal cut.

- `app-icon.png`: 1024px app icon, on a dark rounded tile.
- `mark.png`: 1024px white symbol with transparent background and counters.

Both are generated from `Sources/Quota/RationMark.swift`, which also draws the native 18-point menu-bar template. The app iconset is generated at exact 16–1024px resolutions during packaging. See CONTRIBUTING.md for the regeneration command.
