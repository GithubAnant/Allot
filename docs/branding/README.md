# Allot mark

A chunky lowercase **a**, with one allocation set aside as a floating citrus dot. Bold shapes and a generous counter keep it legible at menu-bar size. The native menu-bar image is monochrome and adapts to the system appearance.

- `app-icon.png`: 1024px app icon on a dark rounded tile.
- `mark.png`: 1024px symbol with transparent background and a citrus accent.

Both are generated from `Sources/Quota/AllotMark.swift`, which also draws the native 18-point menu-bar template. The app iconset is generated at exact 16–1024px resolutions during packaging. See CONTRIBUTING.md for the regeneration command.
